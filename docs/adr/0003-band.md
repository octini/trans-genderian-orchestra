# ADR 0003 — Band mechanism: tool-less lenses + synthesizer, named-override rule

- **Status:** accepted
- **Date:** 2026-08-04
- **Source:** wayfinder decision tgo-a6r.12; `docs/spec/band.md`

## Context

Judgment-heavy decisions need a review surface. Options were: always-on band (too slow/default), a single reviewer (no synthesis), or a lensed band that fires only when warranted. The user's band theming (Cobain/Grohl/Novoselic) was the raw material; the decision is about the *mechanism*: three independent judgment axes + a reconciler, invoked rarely.

## Decision

Nirvana = one synthesizer subagent (strongest model, low temp) + three **tool-less** band-member lenses spawned in parallel at depth 1 (Risk/Structure/Economy; ~50-100 token steering paragraphs). Fires only on orchestrator judgment or user prose. Output = Band Response + per-lens details + Band Summary (confidence: unanimous/majority/split) + **named-override rule** (synthesizer states which lens it overrode and why; no mush). Ephemeral — no beads issues.

## Consequences

- Rare invocation keeps the band cheap.
- Tool-less band members reason purely, cannot act.
- Disagreement is surfaced, never averaged.
- Band output is advisory; Bernstein still owns the call and the beads record.
